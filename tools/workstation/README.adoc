= Workstation toolchain layout

These files describe the toolchain layout of the shared developer workstation that the BoJ kit targets. They are reference material: nothing in this repository sources them.

[cols="1,3"]
|===
| File | What it is

| `env.sh`
| Shell environment that points each toolchain's home (`rustup`, `cargo`, `mise`, `pack`/Idris2, `alire`, `elan`, Julia depot, `opam`, `bun`) at one `tools/opt/` tree instead of `$HOME`, and puts their `bin/` directories on `PATH`. Sourced from `~/.profile` on the workstation.

| `LANGUAGES.adoc`
| Index header for the locally installed languages, with the method key (apt, rustup, cargo, mise, pack, binary, deferred).

| `PROVERS-SOLVERS.adoc`
| Index header for the formal-methods tooling (Agda, Lean, Coq, Idris, TLA+, SPARK, Kani, Creusot, Z3, CVC5, Yices, Why3, Echidna).
|===

== Provenance

Moved on 2026-10-06 from the standalone private repo `hyperpolymath/tools` (last commit `a3c47ed`), which is retired. The live copy on the workstation remains `developer/tools/env.sh`; if the two drift, the workstation copy is the one in use.

One file from that repo was not carried over: `bin/linear-cartridge-mcp`. It launched `tools/cartridge-mcp/serve.js` in `boj-server-cartridges` under Deno, but that file has never existed in any ref of that repository, and Deno is not used in this estate. It is preserved in the owner's offline archive of the retired repo.
