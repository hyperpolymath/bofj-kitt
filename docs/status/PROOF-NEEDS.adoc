It decides which prover carries which obligation. This file records what
that means for this repository. Status lives in `PROOF-STATUS.adoc`.

== Proof tier

// Assign one: T1 (Critical), T2 (High), T3 (Standard), T4 (Light), T5 (Exempt)
*Tier*: T5 — Exempt.

bofj-kitt is shell scripts, manifests and configuration. It has no ABI, no
FFI, no typed API and no theory content, so PROOF-POLICY §1 maps nothing in
it to a prover. Its scripts are covered by tests in `tests/`. Raise the tier
if the repository gains code that §1 maps.

== Escape hatches

`just proof-scan-dangerous` (`scripts/proof-check.sh scan`) fails on these
words in proof code. Comments and string literals are ignored, so a comment
that names a banned word does not trip it.

[cols="2,2,3", options="header"]
|===
|Pattern |Language |Meaning

|`believe_me` |Idris2 |Unchecked cast
|`assert_total` |Idris2 |Skips the totality check
|`postulate` |Agda, Idris2 |Unproven axiom
|`TERMINATING`, `NON_TERMINATING`, `NO_TERMINATION_CHECK` |Agda pragmas |Skips the termination check
|`sorry`, `admit` |Lean 4, Coq |Incomplete proof
|`Admitted` |Coq |Incomplete proof
|`unsafeCoerce` |Haskell |Unchecked cast
|`Obj.magic` |OCaml |Unchecked cast
|===

How escape-hatch debt is budgeted and recorded is set by the standards
repository's `docs/TRUSTED-BASE-REDUCTION-POLICY.adoc`, not here.
