== Summary

bofj-kitt has *no first-party proof obligations*. It is shell scripts,
manifests and configuration, with no ABI, no FFI, no typed API and no
theory content, so the PROOF-POLICY §1 mapping assigns it nothing to
prove. The behaviour of its scripts is covered by the tests in `tests/`,
which are test evidence, not proofs.

Three kinds of proof-shaped files live here, and none of them is an
obligation of this repository:

. RSR template proof files under `verification/proofs/`.
. Prover-exercise fixtures under `tools/proof-toolchain/smoke/`.
  PROOF-POLICY §3 puts corpora that exist to exercise provers outside the
  policy.
. Obligations the proposals name for code that will live in other
  repositories.

== Verification commands

[source,bash]
----
just proof-check-all       # every leg, then the escape-hatch scan
just proof-check-agda      # PROOF-POLICY §2.1 invocation
just proof-check-coq
just proof-check-lean4
just proof-check-idris2
just proof-scan-dangerous  # code only; comments and strings are ignored
----

`scripts/proof-check.sh` exits 0 when every leg passes and 1 when a leg
fails. It exits 3 when no leg failed but a checker was unavailable: a
missing prover is reported, never passed. If the Agda standard library is
not a registered Agda library, set `AGDA_STDLIB` to its source directory.
