= LLM Warmup — bofj-kitt (User)

== What is bofj-kitt?

See `README.adoc` for overview: bofj-kitt is the shared Developer Environment Extension Kit for the BoJ (Box of Justice) server.

== Key Commands

* `just setup` — set up development environment
* `just build` — build the project
* `just test` — run tests
* `just doctor` — diagnose issues
* `just heal` — attempt auto-repair
* `tools/proof-toolchain/provers.sh doctor` — which provers this environment really has (`--json` for the capability record)
